# Paesi con l'articolo TODO

La maggior parte dei paesi (nazioni) in tedesco è neutra e si esprime senza articolo ("_Italien ist sehr schön_"), ma alcuni vogliono l'articolo. Di questi, quelli che si esprimono al singolare hanno un genere definito. Facciamo alcuni esempi (la lista non è esaustiva):

| Paese                                         | Genere    |
| --------------------------------------------- | --------- |
| der Iran                                      | maschile  |
| die Schweiz                                   | femminile |
| der Vatikan                                   | maschile  |
| der Sudan                                     | maschile  |
| die Deutsche Demokratische Republik (die DDR) | femminile |
| die Bahamas                                   | femminile |

Alcuni poi si esprimono al plurale perché sono collezioni di stati o entità: die USA, die Seychellen, ...
